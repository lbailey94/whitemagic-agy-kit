# Empirical Benchmark Report — `whitemagic-agy-kit v3.0.0` (2026-11-21)

> **Reproducibility & Transparency Notice:** Every metric below was measured on local Antigravity CLI (`agy 1.5.14`) sessions and controlled `agy -p` trials using [`benchmarks/run_progressive_bench.py`](./run_progressive_bench.py). Raw JSON receipts are saved in [`track1_results.json`](./track1_results.json), [`track2_live_results.json`](./track2_live_results.json), and [`track2_L3_L4_post_fix.json`](./track2_L3_L4_post_fix.json).
>
> **Important Scientific Disclosure on Track 2 Controls:** In Track 2, the `vanilla` arm ran with `WM_AGY_BENCH_VANILLA=1` (all Wave 3/4 hooks bypassed) and prompt-restricted to built-in tools only, while global `~/.gemini/GEMINI.md` context-hygiene rules remained loaded to avoid mutating live parallel sessions on the host. Therefore, Track 2 deltas measure the **incremental gain of Wave 3/4 deterministic hooks & tools on top of Wave 1/2 rules**—total end-to-end savings vs. stock unconfigured AGY compound with `@leoshen0`'s `-43%` rule savings and `-10.4k`-token plugin pruning.

- **Benchmark Forensics & SIM Follow-Through:**
  1. All 3 arms passed 100% of Rust tests (`rs=True`), 100% of explicit Phase 3/4 behavioral assertions (`spec=True`), and passed `pytest` in-session via `PYTHONPATH=.`/`python3 -m pytest` (the initial harness script omitted `python3 -m` on its external `gt_py` check—fixed in `v3.0.1`).
  2. Inspecting the single `spills=1` event on `wave4_neon`/`wave4_hydrogen` revealed `PYTHONPATH=. pytest -v` bypassed `wm-squeeze` because inline env prefixes were skipped—`v3.0.1` adds a strict `--env` allowlist (`PYTHONPATH`, `RUST_BACKTRACE`, `RUST_LOG`, `NO_COLOR`, `CARGO_TERM_COLOR`) while still hard-refusing `LD_PRELOAD` / arbitrary env vars (`rc=2`).
  3. Notice that even when `vanilla_neon` already benefited from Wave 1/2 rules (achieving `0` spills by manually piping `| tail -n 25`), `wave4_hydrogen` still ran **2.01× faster (`121.7s` vs `244.2s`)** with **43% fewer tool calls**, **25% fewer tool bytes**, and **-12.2% lower credit index** over 17–20 continuous turns—and `wm-handoff` compresses the finished `48k`–`50k` session into a **`678`-token (`-98.6%`)** verbatim handoff crystal for cold resumes.
